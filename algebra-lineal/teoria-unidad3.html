📐 Subespacios vectoriales

Definición — Subespacio de $\mathbb{R}^n$

Un subconjunto $S \subseteq \mathbb{R}^n$ es un subespacio vectorial si y solo si:

  1. $\vec{0} \in S$ (contiene al vector nulo)
  2. $\forall\, u,v \in S \Rightarrow u+v \in S$ (cerrado bajo suma)
  3. $\forall\, u \in S,\, \alpha \in \mathbb{R} \Rightarrow \alpha u \in S$ (cerrado bajo producto escalar)

Subespacio como solución de $Ax=0$

El conjunto solución $S = \{x \in \mathbb{R}^n : Ax = 0\}$ de un sistema homogéneo siempre es un subespacio de $\mathbb{R}^n$. Se llama espacio nulo o núcleo de $A$.

Los subespacios más comunes en los parciales vienen dados por ecuaciones homogéneas.

📏 Dimensión de un subespacio — Rouché aplicado
$\dim(S) = n - \text{Rg}(A)$ $n$ = número de incógnitas · $A$ = matriz del sistema homogéneo · $\text{Rg}(A)$ = rango de $A$

¿Cómo hallar la base?

  1. Escribir la matriz $A$ del sistema homogéneo
  2. Escalonar $A$ con operaciones elementales por filas
  3. Identificar variables pivote y variables libres
  4. Parametrizar las libres: $x_{k_1}=s,\; x_{k_2}=t,\;\ldots$
  5. Expresar el vector solución general como c.l. de vectores fijos → esos son la base

¿S = T? — igualdad de subespacios

Dados $S$ y $T$ con las mismas dimensiones:

  1. Verificar $\dim(S) = \dim(T)$
  2. Armar una matriz $M$ juntando los generadores de ambos
  3. Si $\text{Rg}(M) = \dim(S) = \dim(T)$ → $S = T$
  4. Si $\text{Rg}(M) > \dim(S)$ → $S \neq T$

➕ Suma de subespacios

Definición — Suma $S+T$

$$S + T = \{s + t : s \in S,\; t \in T\}$$

Es el subespacio más pequeño que contiene a $S$ y a $T$.

Criterio práctico: Armá una matriz con todos los vectores generadores de $S$ y de $T$. Si $\text{Rg} = n$ → $S+T=\mathbb{R}^n$.

Teorema de la dimensión

$\dim(S+T) = \dim(S) + \dim(T) - \dim(S\cap T)$

Permite calcular la dimensión de la intersección sin hallarla explícitamente, o verificar si la suma es directa.

Suma directa $S \oplus T$

La suma es directa si $S \cap T = \{0\}$. Equivalentemente:

$$\dim(S \oplus T) = \dim(S) + \dim(T)$$

Todo vector de $S+T$ se escribe de forma única como $s+t$.

Complemento ortogonal $S^\perp$

$$S^\perp = \{v \in \mathbb{R}^n : \langle v, s \rangle = 0 \;\forall s \in S\}$$

Propiedades:

  • $\dim(S^\perp) = n - \dim(S)$
  • $S \oplus S^\perp = \mathbb{R}^n$ (siempre)
  • $(S^\perp)^\perp = S$
🧪 Ejemplo resuelto — Ejercicio 2 estilo parcial

Enunciado

En $\mathbb{R}^3$, sean $S_1 = \{(x,y,z): x+y-z=0\}$ y $S_2 = \{(x,y,z): x-y+z=0\}$. Hallar generadores de $S_1$ y $S_2$. Verificar si $S_1+S_2=\mathbb{R}^3$. Hallar $S_1 \cap S_2$ y decidir si la suma es directa. Hallar $S_1^\perp$ y verificar $S_1 \oplus S_1^\perp = \mathbb{R}^3$.

Parte A — Generadores de $S_1$ y $S_2$

$S_1$: $x+y-z=0 \Rightarrow x = z-y$

$(x,y,z) = (z-y,y,z) = y(-1,1,0) + z(1,0,1)$

$\text{Gen}(S_1) = \{(-1,1,0),\;(1,0,1)\},\quad \dim(S_1)=2$


$S_2$: $x-y+z=0 \Rightarrow x = y-z$

$(x,y,z) = (y-z,y,z) = y(1,1,0) + z(-1,0,1)$

$\text{Gen}(S_2) = \{(1,1,0),\;(-1,0,1)\},\quad \dim(S_2)=2$

Parte B — ¿$S_1+S_2 = \mathbb{R}^3$?

Armamos la matriz con los 4 generadores como filas:

-110$\leftarrow v_1^{(S_1)}$
101$\leftarrow v_2^{(S_1)}$
110$\leftarrow v_1^{(S_2)}$
-101$\leftarrow v_2^{(S_2)}$

Escalonando, el rango de esta matriz es 3 (hay 3 vectores LI entre los 4). Por lo tanto $\text{Rg}=3=\dim(\mathbb{R}^3)$ → $S_1+S_2 = \mathbb{R}^3$ ✅

Parte C — $S_1 \cap S_2$ y suma directa

Resolvemos el sistema combinado $x+y-z=0$ y $x-y+z=0$:

  • Sumando: $2x=0 \Rightarrow x=0$
  • Sustituyendo: $y-z=0 \Rightarrow y=z$

$S_1 \cap S_2 = \{(0,y,y): y\in\mathbb{R}\} = \text{span}\{(0,1,1)\}$

$\dim(S_1 \cap S_2) = 1$

Teorema de la dimensión: $\dim(S_1+S_2) = 2+2-1 = 3$ ✓

Como $S_1 \cap S_2 \neq \{0\}$, la suma NO es directa.

Parte D — Complemento ortogonal $S_1^\perp$

Buscamos $w=(w_1,w_2,w_3)$ tal que $w \perp (-1,1,0)$ y $w \perp (1,0,1)$:

$\langle w, (-1,1,0)\rangle = 0 \Rightarrow -w_1+w_2=0 \Rightarrow w_1=w_2$

$\langle w, (1,0,1)\rangle = 0 \Rightarrow w_1+w_3=0 \Rightarrow w_3=-w_1$

Tomando $w_1=1$: $w = (1,1,-1)$

$$S_1^\perp = \text{span}\{(1,1,-1)\},\quad \dim(S_1^\perp) = 1$$

Verificación $S_1 \oplus S_1^\perp = \mathbb{R}^3$:

  • $\dim(S_1) + \dim(S_1^\perp) = 2+1 = 3 = \dim(\mathbb{R}^3)$ ✓
  • $S_1 \cap S_1^\perp = \{0\}$ (un vector perpendicular a sí mismo tiene norma 0) ✓
  • Por tanto $S_1 \oplus S_1^\perp = \mathbb{R}^3$ ✅

📌 Coordenadas en una base

Definición — Coordenadas $[v]_B$

Si $B=\{b_1,\ldots,b_n\}$ es base de $\mathbb{R}^n$, todo $v\in\mathbb{R}^n$ se escribe de forma única como:

$v = \alpha_1 b_1 + \alpha_2 b_2 + \cdots + \alpha_n b_n$

Los escalares $(\alpha_1,\ldots,\alpha_n)$ se llaman coordenadas de $v$ en la base $B$, escritas $[v]_B$.

Proceso — cómo calcular $[v]_B$

  1. Plantear $\alpha_1 b_1 + \cdots + \alpha_n b_n = v$
  2. Armar la matriz ampliada $[B\,|\,v]$ donde las columnas de $B$ son los vectores de la base
  3. Resolver el sistema por Gauss-Jordan
  4. Las soluciones son $[v]_B = (\alpha_1,\ldots,\alpha_n)$
💡
Si la base es la canónica $E = \{e_1,\ldots,e_n\}$, entonces $[v]_E = v$ (las coordenadas son las componentes habituales). La gracia aparece con bases no canónicas.

🔁 Transformaciones lineales

Definición — Transformación lineal

$T:\mathbb{R}^n \to \mathbb{R}^m$ es transformación lineal si:

  • $T(u+v) = T(u) + T(v)$ para todo $u,v\in\mathbb{R}^n$
  • $T(\alpha u) = \alpha\, T(u)$ para todo $\alpha\in\mathbb{R}$, $u\in\mathbb{R}^n$

Equivalente: $T(\alpha u + \beta v) = \alpha T(u) + \beta T(v)$

Consecuencias inmediatas

  • $T(\vec{0}) = \vec{0}$ (el nulo va al nulo)
  • $T(-v) = -T(v)$
  • $T\left(\sum \alpha_i v_i\right) = \sum \alpha_i T(v_i)$ (linearidad de c.l.)

Esta última propiedad es la clave para el Ejercicio 4 del parcial.

🔑 Existencia y unicidad

Teorema fundamental (Ejercicio 4 del parcial)

Si $\{v_1,v_2,\ldots,v_n\}$ es base de $\mathbb{R}^n$ y $w_1,\ldots,w_n \in \mathbb{R}^m$ son vectores cualesquiera del codominio, entonces existe una única transformación lineal $T:\mathbb{R}^n\to\mathbb{R}^m$ tal que $T(v_i)=w_i$ para todo $i$.

¿Cuándo forman base? Los $v_i$ forman base si $\det[v_1\mid v_2\mid\cdots\mid v_n] \neq 0$ (o equivalentemente, $\text{Rg}=n$).

🧪 Ejemplo resuelto — Ejercicio 4 estilo parcial

Enunciado

Sea $T:\mathbb{R}^3\to\mathbb{R}^3$ lineal tal que $T(1,0,1)=(1,1,0)$, $T(0,1,0)=(0,1,1)$ y $T(1,1,0)=(1,0,1)$. (a) Verificar que $\{v_1,v_2,v_3\}=\{(1,0,1),(0,1,0),(1,1,0)\}$ es base de $\mathbb{R}^3$. (b) Hallar $T(e_1), T(e_2), T(e_3)$. (c) Escribir la fórmula general de $T$.

Parte (a) — Verificar que es base

Armamos la matriz con los vectores como filas y calculamos el determinante:

101
010
110

$\det = 1\cdot(1\cdot0-0\cdot1) - 0 + 1\cdot(0\cdot1-1\cdot1) = 0 + 0 + (0-1) = -1 \neq 0$

✅ Los tres vectores son LI → forman base de $\mathbb{R}^3$ → existe una única TL que los transforma en los valores dados.

Parte (b) — Hallar $T(e_1), T(e_2), T(e_3)$

Expresamos cada vector canónico en la base $\{v_1,v_2,v_3\}$. Para $e_j = \alpha v_1 + \beta v_2 + \gamma v_3$, necesitamos resolver:

$\alpha(1,0,1)+\beta(0,1,0)+\gamma(1,1,0)=(x_1,x_2,x_3)$

El sistema es: $\alpha+\gamma=x_1$; $\beta+\gamma=x_2$; $\alpha=x_3$


Para $e_1=(1,0,0)$: $\alpha=0$, $\alpha+\gamma=1\Rightarrow\gamma=1$, $\beta+\gamma=0\Rightarrow\beta=-1$

$T(e_1) = 0\cdot T(v_1) + (-1)\cdot T(v_2) + 1\cdot T(v_3) = 0-(0,1,1)+(1,0,1) = (1,-1,0)$


Para $e_2=(0,1,0)$: $\alpha=0$, $\alpha+\gamma=0\Rightarrow\gamma=0$, $\beta+\gamma=1\Rightarrow\beta=1$

$T(e_2) = 0\cdot T(v_1) + 1\cdot T(v_2) + 0\cdot T(v_3) = T(v_2) = (0,1,1)$


Para $e_3=(0,0,1)$: $\alpha=1$, $\alpha+\gamma=0\Rightarrow\gamma=-1$, $\beta+\gamma=0\Rightarrow\beta=1$

$T(e_3) = 1\cdot T(v_1) + 1\cdot T(v_2) + (-1)\cdot T(v_3) = (1,1,0)+(0,1,1)-(1,0,1) = (0,2,0)$

Parte (c) — Fórmula general de $T$

Usando linealidad: $T(x_1,x_2,x_3) = x_1 T(e_1) + x_2 T(e_2) + x_3 T(e_3)$

$= x_1(1,-1,0) + x_2(0,1,1) + x_3(0,2,0)$

$$\boxed{T(x_1,x_2,x_3) = \big(x_1,\; -x_1+x_2+2x_3,\; x_2\big)}$$

✅
Verificación: $T(1,0,1)=(1,-1+0+2,0)=(1,1,0)$ ✓  |  $T(0,1,0)=(0,0+1+0,1)=(0,1,1)$ ✓  |  $T(1,1,0)=(1,-1+1+0,1)=(1,0,1)$ ✓

📊 Núcleo e imagen

Núcleo $\ker(T)$

$\ker(T) = \{x \in \mathbb{R}^n : T(x) = 0\}$

Es un subespacio de $\mathbb{R}^n$. Se halla resolviendo el sistema homogéneo con la matriz de $T$.

$\dim(\ker T) = $ nullidad de $T$.

Imagen $\text{Im}(T)$

$\text{Im}(T) = \{T(x) : x \in \mathbb{R}^n\}$

Es un subespacio de $\mathbb{R}^m$. Generado por las columnas de la matriz de $T$.

Teorema rango-nulidad: $\dim(\ker T) + \dim(\text{Im}\, T) = n$

⚠️ Errores frecuentes

⚠️ No verificar que es base antes de concluir unicidad de TL

Si los vectores del dominio NO son base, puede no existir o no ser única la TL. Siempre verificar det≠0.

⚠️ Confundir dim(S+T) con dim(S)+dim(T)

Esa fórmula solo vale si la suma es directa. En general hay que restar la dimensión de la intersección.

⚠️ Al buscar S⊥, olvidar un generador

Si S tiene 2 generadores, el sistema para S⊥ tiene 2 ecuaciones. Con 1 solo generador se puede pasar por alto la segunda condición.

⚠️ Coordenadas: confundir filas con columnas

En $[B|v]$, los vectores de la base van como columnas de $B$ (porque la ec. es $B\alpha=v$). Si ponés los vectores como filas transpuesta el sistema.

⚡ EJ1 — Subespacio como solución de Ax=0 (5 min)

Qué te piden: base y dim de $S=\{x\in\mathbb{R}^n: Ax=0\}$.

Receta:

  1. Escalonar $A$ con operaciones de fila.
  2. Contar pivotes → eso es Rg(A).
  3. $\dim(S) = n - \text{Rg}(A)$ → esa es la cantidad de vectores en la base.
  4. Las variables libres son los parámetros $s, t, \ldots$. Despejar las pivote en función de las libres.
  5. Escribir el vector solución general: cada parámetro da un vector de la base.

Pitfall: no olvides que el sistema es homogéneo (término independiente = 0). No hace falta armar la columna b.

⚡ EJ2 — Suma y complemento ortogonal (5 min)

Generadores de un subespacio definido por ecuaciones: despejá una variable en función de las otras (variables libres) → cada variable libre da un generador.

¿S+T = Rⁿ? Armá una matriz con todos los generadores. Si el rango es $n$ → sí.

Suma directa: usar Teorema de la dim para hallar dim(S∩T). Si es 0 → suma directa.

Complemento ortogonal $S^\perp$: plantear sistema de productos internos = 0 con cada generador de S. Las soluciones (variables libres) generan $S^\perp$. Verificar $\dim(S)+\dim(S^\perp)=n$.

⚡ EJ3 — Coordenadas en una base (5 min)

Sistema a resolver: $\alpha_1 b_1 + \cdots + \alpha_n b_n = v$ → matriz $[B|v]$ donde columnas de B = vectores de la base.

Gauss-Jordan → solución única (B es base → det≠0 → siempre única solución).

Verificación rápida: $\alpha_1 b_1 + \alpha_2 b_2 + \alpha_3 b_3$ tiene que dar exactamente $v$. No saltees este paso en el parcial.

⚡ EJ4 — Transformación lineal (5 min)

Paso 1: armar la matriz con $\{v_1,v_2,v_3\}$ como filas (o columnas) y calcular el determinante. Si det≠0 → única TL. Siempre escribir "por lo tanto existe una única TL".

Paso 2: para cada $e_j$ resolver $\alpha_1 v_1 + \alpha_2 v_2 + \alpha_3 v_3 = e_j$ (mismo sistema 3×3, solo cambia el lado derecho). Usar linealidad: $T(e_j) = \alpha_1 T(v_1) + \alpha_2 T(v_2) + \alpha_3 T(v_3)$.

Paso 3: $T(x_1,x_2,x_3) = x_1 T(e_1) + x_2 T(e_2) + x_3 T(e_3)$. Expandir y simplificar.

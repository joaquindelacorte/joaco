📐 Tema 0 · Reglas de derivación

EJ 0.1
Derivación básica (potencia y suma)
Derivar las siguientes funciones:
  • a) $f(x) = 3x^5 - 2x^3 + 7x - 4$
  • b) $g(x) = \dfrac{1}{x^2}$ (escribir como $x^{-2}$)
  • c) $h(x) = \sqrt{x}$ (escribir como $x^{1/2}$)

✅ Resolución paso a paso

a
Regla de potencia + suma/resta + múltiplo constante
Cada término es un monomio: $(c\cdot x^n)' = c\cdot n\cdot x^{n-1}$, y las derivadas se suman.
$f'(x) = 3\cdot 5x^4 - 2\cdot 3x^2 + 7\cdot 1 - 0 = 15x^4 - 6x^2 + 7$
$f'(x) = 15x^4 - 6x^2 + 7$
b
Reescribir como potencia y aplicar regla
$g(x) = x^{-2} \Rightarrow g'(x) = -2\cdot x^{-3}$
Cuando hay fracciones del tipo $1/x^n$, conviene reescribir con exponente negativo. Evita usar la regla del cociente.
$g'(x) = -\dfrac{2}{x^3}$
c
Raíz como potencia fraccionaria
$h(x) = x^{1/2} \Rightarrow h'(x) = \tfrac{1}{2}\cdot x^{-1/2}$
$\sqrt{x} = x^{1/2}$. Bajo el exponente y se le resta 1: $1/2 - 1 = -1/2$.
$h'(x) = \dfrac{1}{2\sqrt{x}}$
EJ 0.2
Regla del producto
Derivar $f(x) = (x^2 + 1)(x^3 - 2x)$

✅ Resolución paso a paso

1
Identificar u, v, u', v'
$u = x^2 + 1 \Rightarrow u' = 2x$
$v = x^3 - 2x \Rightarrow v' = 3x^2 - 2$
2
Aplicar $(uv)' = u'v + uv'$
$f'(x) = (2x)(x^3 - 2x) + (x^2 + 1)(3x^2 - 2)$
3
Desarrollar y simplificar
$f'(x) = 2x^4 - 4x^2 + 3x^4 - 2x^2 + 3x^2 - 2$
$f'(x) = 5x^4 - 3x^2 - 2$
Verificación: expandiendo primero $f(x) = x^5 - x^3 - 2x$, su derivada es $5x^4 - 3x^2 - 2$ ✓
$f'(x) = 5x^4 - 3x^2 - 2$
EJ 0.3
Regla del cociente
Derivar $f(x) = \dfrac{2x}{x^2 + 1}$

✅ Resolución paso a paso

1
Identificar u, v, u', v'
$u = 2x \Rightarrow u' = 2$
$v = x^2 + 1 \Rightarrow v' = 2x$
2
Aplicar $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$
$f'(x) = \dfrac{2(x^2+1) - 2x(2x)}{(x^2+1)^2}$
⚠️ El orden es u'v menos uv' (no al revés).
3
Simplificar el numerador
$f'(x) = \dfrac{2x^2 + 2 - 4x^2}{(x^2+1)^2} = \dfrac{2 - 2x^2}{(x^2+1)^2}$
$f'(x) = \dfrac{2(1 - x^2)}{(x^2 + 1)^2}$
EJ 0.4
Sensibilidad de sensor de temperatura
$V(T) = 0{,}01T^2 + 0{,}5T + 2$ (T en °C, V en voltios).
  • a) Hallar la sensibilidad $V'(T)$.
  • b) Sensibilidad en $T = 50$°C y $T = 100$°C.
  • c) ¿Qué significa que la sensibilidad aumente con T?

✅ Resolución paso a paso

a
Derivar V(T)
$V'(T) = 0{,}02T + 0{,}5$ V/°C
La sensibilidad es la derivada: cuánto cambia el voltaje por cada °C extra.
b
Evaluar en los puntos pedidos
$V'(50) = 0{,}02(50) + 0{,}5 = 1{,}0 + 0{,}5 = \mathbf{1{,}5}$ V/°C

$V'(100) = 0{,}02(100) + 0{,}5 = 2{,}0 + 0{,}5 = \mathbf{2{,}5}$ V/°C
c
Interpretación física

Significa que el sensor es no lineal: a temperaturas más altas, un mismo $\Delta T$ produce mayor $\Delta V$.

El PLC debe linealizar la lectura antes de tomar decisiones (mediante tabla de conversión o algoritmo de compensación). Si no, las lecturas a alta temperatura tendrán mayor error relativo.

EJ 0.5
Velocidad de actuador lineal
$x(t) = 2t^3 - 9t^2 + 12t$ (cm, s).
  • a) Hallar $v(t) = x'(t)$.
  • b) ¿En qué instante(s) $v = 0$?
  • c) ¿Qué ocurre físicamente?

✅ Resolución paso a paso

a
Derivar la posición
$v(t) = x'(t) = 6t^2 - 18t + 12$ cm/s
b
Buscar instantes con velocidad nula
$6t^2 - 18t + 12 = 0$
$6(t^2 - 3t + 2) = 0$
$6(t-1)(t-2) = 0$

$\Rightarrow t = 1$ s  ó  $t = 2$ s
c
Interpretación física

El actuador cambia de sentido en esos instantes. Analizando los intervalos:

  • $0 < t < 1$: $v > 0$ → avanza
  • $1 < t < 2$: $v < 0$ → retrocede
  • $t > 2$: $v > 0$ → avanza de nuevo

Es un movimiento típico de pick & place: avanza → vuelve → sigue.

EJ 1.1
Llenado de tanque con caudal variable
$Q(t) = 8 - 2t$ L/s, intervalo $[0, 4]$ s.
  • a) Volumen entre $t=0$ y $t=2$ s.
  • b) Volumen entre $t=2$ y $t=4$ s.

✅ Resolución paso a paso

0

$\int (8-2t)\,dt = 8t - t^2 + C \Rightarrow F(t) = 8t - t^2$
a

$V_{[0,2]} = F(2) - F(0) = (16 - 4) - 0 = 12$ L
$V_{[0,2]} = 12$ L
b
Volumen en [2, 4]
$V_{[2,4]} = F(4) - F(2) = (32 - 16) - (16 - 4) = 16 - 12 = 4$ L
$V_{[2,4]} = 4$ L
c
Volumen total [0, 4]
$V_{total} = F(4) - F(0) = 16 - 0 = 16$ L
Verificación: $12 + 4 = 16$ ✓. En $t=4$ el caudal $Q(4) = 0$: el llenado se detiene justo al final.
$V_{total} = 16$ L

$V = F(2) - F(0) = (8 + 4) - 0 = 12$ L

📊 Tema 4 · Área entre curvas (Efecto Joule)

EJ 4.1
Eficiencia energética en servomotor
$f(x) = \sqrt{x}$ kW (eléctrica), $g(x) = x^2$ kW (mecánica útil), $x \in [0, 1]$ min.
  • a) Intersecciones.
  • b) Área encerrada.
  • c) Interpretación técnica (Efecto Joule).

✅ Resolución paso a paso

a
Encontrar las intersecciones
$\sqrt{x} = x^2 \Rightarrow x = x^4 \Rightarrow x(x^3 - 1) = 0$
$\Rightarrow x = 0$ ó $x = 1$
b
Identificar cuál curva está arriba en [0,1]

Probando en $x = 0{,}5$: $\sqrt{0{,}5} \approx 0{,}71$, $(0{,}5)^2 = 0{,}25$.

Entonces $\sqrt{x} \geq x^2$ en $[0,1]$ → la eléctrica está por encima de la mecánica útil.

Área = $\displaystyle\int_0^1 (\sqrt{x} - x^2)\,dx$

$= \left[\tfrac{2}{3}x^{3/2} - \tfrac{1}{3}x^3\right]_0^1 = \tfrac{2}{3} - \tfrac{1}{3} = \tfrac{1}{3}$
Área $= \dfrac{1}{3}$ kW·min ≈ 20 kJ
c
Interpretación técnica

El área entre la potencia eléctrica suministrada y la potencia mecánica útil representa la pérdida térmica por Efecto Joule.

Es energía eléctrica que no se convirtió en trabajo mecánico: se disipa como calor en bobinados y resistencias internas del servomotor.

Implicancia ingenieril: hay que dimensionar correctamente el disipador térmico y la ventilación del servomotor para esos ~20 kJ por minuto.

📊 Tema 5 · Sumas de Riemann vs Barrow (PLC)

EJ 5.1
Distancia de frenado de motor
$v(t) = 3t^2 + 1$ m/s, $[0, 1]$ s.
  • a) Distancia exacta por Barrow.
  • b) PLC con $\Delta t = 0{,}5$ s (Riemann izquierda, $t_0=0$ y $t_1=0{,}5$).
  • c) Error porcentual.
  • d) Análisis crítico: consecuencias en un brazo robótico y cómo solucionarlo.

✅ Resolución paso a paso

a
Distancia exacta (Barrow)
Primitiva: $F(t) = t^3 + t$

$d_{exacta} = F(1) - F(0) = (1 + 1) - 0 = 2$ m
$d_{exacta} = 2$ m
b
PLC Riemann izquierda
$v(0) = 1$ m/s   $v(0{,}5) = 3(0{,}25) + 1 = 1{,}75$ m/s

$d_{PLC} = v(0)\cdot 0{,}5 + v(0{,}5)\cdot 0{,}5 = 0{,}5 + 0{,}875 = 1{,}375$ m
$d_{PLC} = 1{,}375$ m
c
Error porcentual
$\text{Error \%} = \dfrac{|2 - 1{,}375|}{2}\cdot 100\% = \dfrac{0{,}625}{2}\cdot 100\% = 31{,}25\%$
Error ≈ 31,25%
d
Análisis crítico

En un brazo robótico, un error del 31% en la distancia de frenado significa que el robot puede pasarse del punto previsto en casi un tercio. Si la lógica activa una parada de emergencia, llegaría tarde → colisión.

Soluciones:

  • ✅ Reducir $\Delta t$ (muestrear más rápido)
  • ✅ Usar regla del trapecio en vez de rectángulos
  • ✅ Sensor de proximidad redundante
  • ✅ Margen de seguridad en el setpoint de parada
EJ 5.2
PLC con datos tabulados
$\Delta t = 0{,}2$ s. Datos:
t (s)0,00,20,40,60,81,0
v (m/s)1,001,121,482,082,924,00
Distancia por Riemann izquierda. Reflexión sobre ventajas/desventajas.

✅ Resolución paso a paso

1
Identificar las muestras "por izquierda"

Riemann izquierda: extremo izquierdo de cada subintervalo. Tenemos 5 subintervalos en [0,1], evaluamos en $t = 0; 0{,}2; 0{,}4; 0{,}6; 0{,}8$ (NO usamos $t=1$).

Valores: 1,00 + 1,12 + 1,48 + 2,08 + 2,92 = 8,60
2
Aplicar la suma de Riemann
$d_{PLC} = \sum v(t_i)\cdot \Delta t = 8{,}60 \cdot 0{,}2 = 1{,}72$ m
$d_{PLC} = 1{,}72$ m
3
Reflexión

Ventajas:

  • Computacionalmente trivial: suma + multiplicación.
  • El PLC lo ejecuta en microsegundos.
  • No requiere conocer la fórmula analítica de v(t).

Desventajas:

  • Error de discretización.
  • Subestima si v es creciente, sobreestima si es decreciente.
  • Requiere muestreo fino para precisión.
EJ 5.3
Error del PLC vs Barrow (continuación 5.2)
Velocidad teórica: $v(t) = 3t^2 + 1$ m/s.
  1. Distancia exacta entre $t=0$ y $t=1$ por Barrow.
  2. Error porcentual del PLC (Ej. 5.2) respecto al valor exacto.
¿Es aceptable para alta precisión? ¿Cómo reducirlo?

✅ Resolución paso a paso

1
Distancia exacta
$d_{exacta} = \displaystyle\int_0^1 (3t^2 + 1)\,dt = [t^3 + t]_0^1 = 2$ m
2
Error porcentual
$\text{Error \%} = \dfrac{|2 - 1{,}72|}{2}\cdot 100\% = \dfrac{0{,}28}{2}\cdot 100\% = 14\%$
Error ≈ 14%
3
Análisis crítico

14% es demasiado alto para un brazo robótico de alta precisión (típicamente se requiere < 1%).

Soluciones:

EJ 5.4
Error de muestreo en nodo industrial (simulacro)
$Q(t) = 3t^2 + 2$ L/s, $[0, 2]$ s, $\Delta t = 1$ s.
  • a) Volumen exacto.
  • b) Volumen aproximado (Riemann izq, $t_0=0, t_1=1$).
  • c) Error % y consecuencias.

✅ Resolución paso a paso

a
Volumen exacto (Barrow)
$F(t) = t^3 + 2t$
$V_{exacto} = F(2) - F(0) = 12 - 0 = 12$ L
b
PLC Riemann izquierda
$Q(0) = 2$, $Q(1) = 5$
$V_{PLC} = 2\cdot 1 + 5\cdot 1 = 7$ L
c
Error y consecuencias críticas
$\text{Error \%} = \dfrac{|12 - 7|}{12}\cdot 100\% \approx 41{,}67\%$

El PLC subestima el volumen real en ~42%. Si el lazo de control evita el desborde de un tanque crítico:

  • 🚨 No detectará a tiempo la condición de riesgo.

🎚️ Tema 6 · Acción integral del PID (Windup)

EJ 6.1
Diagnóstico de falla por saturación
Motor trabado mecánicamente. Error fijo $e(t) = 5$ unidades durante 4 s. PID con $K_i = 2$: $$u_i(t) = K_i\int_0^t e(\tau)\,d\tau$$
  1. Valor analítico de $u_i$ a los 4 s.
  2. ¿Qué pasa si no se soluciona? ($t \to \infty$)
  3. Cuando la traba se suelta de golpe, ¿qué ocurre? Nombre del fenómeno.

✅ Resolución paso a paso

1
Señal integral a los 4 s
$u_i(4) = 2\cdot\displaystyle\int_0^4 5\,d\tau = 2\cdot 5\cdot 4 = 40$
$u_i(4) = 40$ unidades
2
Comportamiento si no se soluciona
$u_i(t) = 2\cdot 5\cdot t = 10t$

$\displaystyle\lim_{t\to\infty} u_i(t) = +\infty$

La señal de control crece sin límite.

3
Análisis técnico

Cuando la traba se suelta de golpe, el motor recibe una señal de control acumulada enorme:

  • 🚨 Arranque violento
  • 🚨 Posibles daños mecánicos (sobre-par, sobre-velocidad)
  • 🚨 Pérdida de precisión durante el transitorio brusco

Nombre del fenómeno: Integral Windup (saturación integral).

Solución de ingeniería: implementar anti-windup: limitar la acumulación cuando el actuador satura, o resetear el integrador.

🔍 Tema 7 · Clasificación de EDOs

EJ 7.1
Clasificar orden y linealidad
Determinar orden y linealidad de:
  • a) $\dfrac{dy}{dt} + 4t^2 y = \cos(t)$
  • b) $\dfrac{d^2y}{dt^2} + 3\dfrac{dy}{dt} - y^2 = 0$
  • c) $L\dfrac{di}{dt} + Ri = E\sin(\omega t)$
  • d) $\dfrac{dx}{dt} = k\sqrt{x}$

✅ Resolución paso a paso

EDOOrdenLinealidadJustificación
a)1Lineal$y$ a la potencia 1, coef en $t$ permitidos
b)2NO lineal$y^2$ rompe linealidad
c)1Lineal$i$ a la 1, coeficientes constantes
d)1NO lineal$\sqrt{x} = x^{1/2}$ rompe linealidad
Recordá: el ORDEN es la derivada más alta. La LINEALIDAD requiere que $y$ y sus derivadas aparezcan a la potencia 1, sin funciones no lineales de $y$ (no $\sin y$, no $y^2$, no $\sqrt{y}$).

📐 Tema 8 · Variables separables (solución general)

EJ 8.1
Tres EDOs separables
Hallar solución general:
  • a) $\dfrac{dy}{dt} = \dfrac{t^2}{y}$
  • b) $\dfrac{dy}{dt} = 3t^2(y - 1)$
  • c) $t\dfrac{dx}{dt} = x\ln(x)$

✅ Resolución paso a paso

a
Caso a)
Separar: $y\,dy = t^2\,dt$

Integrar: $\dfrac{y^2}{2} = \dfrac{t^3}{3} + C$

Despejar: $y^2 = \dfrac{2t^3}{3} + C_1$
$y(t) = \pm\sqrt{\dfrac{2t^3}{3} + C_1}$
b
Caso b)
Separar: $\dfrac{dy}{y-1} = 3t^2\,dt$

Integrar: $\ln|y-1| = t^3 + C$

Despejar: $y - 1 = A\,e^{t^3}$
$y(t) = 1 + A\,e^{t^3}$
c
Caso c)
Separar: $\dfrac{dx}{x\ln x} = \dfrac{dt}{t}$

Sustitución $u = \ln x$, $du = dx/x$:
$\displaystyle\int\dfrac{du}{u} = \ln|u| = \ln|\ln x|$

$\ln|\ln x| = \ln|t| + C \Rightarrow \ln x = A\cdot t$
$x(t) = e^{At}$

🎯 Tema 9 · Problemas de valor inicial (PVI)

EJ 9.1
PVI básicos
  • a) $\dfrac{dy}{dt} = -2ty$ con $y(0) = 5$
  • b) $\dfrac{dx}{dt} = \dfrac{e^t}{x}$ con $x(0) = 2$

✅ Resolución paso a paso

a
Caso a)
Separar: $\dfrac{dy}{y} = -2t\,dt$

Integrar: $\ln|y| = -t^2 + C$

Despejar: $y = A\,e^{-t^2}$

Aplicar CI: $y(0) = A = 5$
$y(t) = 5\,e^{-t^2}$
b
Caso b)
Separar: $x\,dx = e^t\,dt$

Integrar: $\dfrac{x^2}{2} = e^t + C$

Aplicar CI $x(0)=2$: $\dfrac{4}{2} = e^0 + C \Rightarrow 2 = 1 + C \Rightarrow C = 1$

$x^2 = 2e^t + 2$
$x(t) = \sqrt{2e^t + 2}$

🌡️ Tema 10 · EDO de Newton (térmico)

EJ 10.1
Tanque mezclador industrial
$\dfrac{dT}{dt} = -k(T - T_a)$ con $k = 0{,}1$ min⁻¹, $T_a = 20$°C, $T(0) = 80$°C.
  • a) Resolver y hallar $T(t)$ particular.
  • b) Calcular $T$ a los 10 min.
  • c) $\lim_{t\to\infty} T(t)$ y significado físico.

✅ Resolución paso a paso

1
Separar y resolver
$\dfrac{dT}{T-20} = -0{,}1\,dt$

$\ln|T-20| = -0{,}1\,t + C$

$T - 20 = A\,e^{-0{,}1 t}$

$T(t) = 20 + A\,e^{-0{,}1 t}$ (general)
a
Aplicar T(0) = 80
$80 = 20 + A \Rightarrow A = 60$
$T(t) = 20 + 60\,e^{-0{,}1 t}$
b
T a los 10 min
$T(10) = 20 + 60\cdot e^{-1} = 20 + 60\cdot 0{,}3679 \approx 20 + 22{,}07$
$T(10) \approx 42{,}07$ °C
c
Asíntota e interpretación
$\displaystyle\lim_{t\to\infty} T(t) = 20 + 60\cdot 0 = 20$ °C

Significado: el fluido se equilibra térmicamente con el ambiente. No puede enfriarse por debajo de los 20°C sin un sistema activo de refrigeración.

EJ 10.2
Enfriamiento de caldera (simulacro)
$\dfrac{dT}{dt} = -0{,}2(T - 25)$, $T(0) = 125$°C.
  • a) Solución general.
  • b) Solución particular.
  • c) Asíntota y significado.

✅ Resolución paso a paso

a
Solución general (separar e integrar)
$\dfrac{dT}{T-25} = -0{,}2\,dt \Rightarrow \ln|T-25| = -0{,}2\,t + C$

$T - 25 = A\,e^{-0{,}2 t}$
$T(t) = 25 + A\,e^{-0{,}2 t}$
b
Aplicar CI T(0) = 125
$125 = 25 + A \Rightarrow A = 100$
$T(t) = 25 + 100\,e^{-0{,}2 t}$
c
Asíntota
$\displaystyle\lim_{t\to\infty} T(t) = 25$ °C

La caldera se enfría hasta equilibrio térmico con el ambiente (25 °C). Es un transitorio exponencial — nunca llega exactamente, pero a los $5\tau = 25$ min está al 99,3%.

💧 Tema 11 · EDO hidráulica

EJ 11.1
Llenado con caudal de entrada constante
$A = 2$ m², $Q_{in} = 4$ m³/min, $Q_{out} = 2h$, $h(0) = 0$.
$A\dfrac{dh}{dt} = Q_{in} - Q_{out}$
  • a) Hallar $h(t)$.
  • b) Altura estacionaria con límites.

✅ Resolución paso a paso

1
Sustituir y simplificar
$2\dfrac{dh}{dt} = 4 - 2h \Rightarrow \dfrac{dh}{dt} = 2 - h$
2
Separar e integrar
$\dfrac{dh}{2-h} = dt \Rightarrow -\ln|2-h| = t + C$

$2 - h = A\,e^{-t} \Rightarrow h(t) = 2 - A\,e^{-t}$
a
Aplicar CI h(0) = 0
$0 = 2 - A \Rightarrow A = 2$
$h(t) = 2(1 - e^{-t})$ m
b
Altura estacionaria
$\displaystyle\lim_{t\to\infty} h(t) = 2(1 - 0) = 2$ m
En régimen permanente $dh/dt = 0$, así que $Q_{in} = Q_{out}$: $4 = 2h \Rightarrow h = 2$ ✓
$h_\infty = 2$ m
EJ 11.2
Vaciado por Torricelli
$\dfrac{dh}{dt} = -k\sqrt{h}$, $h(0) = H_0$. Solución particular.

✅ Resolución paso a paso

1
Separar e integrar
$h^{-1/2}\,dh = -k\,dt$

$2h^{1/2} = -kt + C$

$\sqrt{h} = \dfrac{-kt + C}{2}$
2
Aplicar CI h(0) = H₀
$\sqrt{H_0} = \dfrac{C}{2} \Rightarrow C = 2\sqrt{H_0}$
$h(t) = \left(\sqrt{H_0} - \dfrac{k\,t}{2}\right)^2$
3
Tiempo de vaciado
$h = 0 \Rightarrow \sqrt{H_0} = \dfrac{kt}{2} \Rightarrow t_{vac} = \dfrac{2\sqrt{H_0}}{k}$
A diferencia del enfriamiento exponencial, Torricelli SÍ se vacía en tiempo finito.
EJ 11.3
Descarga constante
$Q_s = 2$ L/s constante, $Q_e = 0$, $V_0 = 10$ L. Tiempo de vaciado.

✅ Resolución paso a paso

1
Balance de masa con Q constante
$\dfrac{dV}{dt} = -2 \Rightarrow V(t) = V_0 - 2t = 10 - 2t$

$V = 0 \Rightarrow t = 5$ s
$t_{vac} = 5$ s

⚡ Tema 12 · Circuito RL

EJ 12.1
Transitorio en circuito RL
$L\dfrac{di}{dt} + Ri = E$, con $i(0) = 0$.
  • Resolver por variables separables.
  • Demostrar que $i(t) = \dfrac{E}{R}(1 - e^{-Rt/L})$.
  • Valor estacionario.

✅ Resolución paso a paso

1
Reescribir y separar
$L\dfrac{di}{dt} = E - Ri \Rightarrow \dfrac{L\,di}{E - Ri} = dt$
2
Integrar

Sustitución $u = E - Ri$, $du = -R\,di$:

$\displaystyle\int\dfrac{L}{u}\cdot\dfrac{du}{-R} = \int dt$

$-\dfrac{L}{R}\ln|u| = t + C$

$\ln|E - Ri| = -\dfrac{R}{L}t + C_1$

$E - Ri = A\,e^{-Rt/L}$

$i(t) = \dfrac{E}{R} - \dfrac{A}{R}\,e^{-Rt/L}$
3
Aplicar CI i(0) = 0
$0 = \dfrac{E}{R} - \dfrac{A}{R} \Rightarrow A = E$
$i(t) = \dfrac{E}{R}\left(1 - e^{-Rt/L}\right)$ ✓
4
Valor estacionario
$\displaystyle\lim_{t\to\infty} i(t) = \dfrac{E}{R}(1 - 0) = \dfrac{E}{R}$
Es la Ley de Ohm: en régimen permanente, la inductancia no aporta resistencia.
$I_{ss} = \dfrac{E}{R}$

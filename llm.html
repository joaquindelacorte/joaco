🧠¿Qué es un LLM?

Definición

Un LLM (Large Language Model) es una red neuronal entrenada con enormes cantidades de texto para hacer una sola cosa muy bien: predecir cuál es la palabra (o "token") más probable que sigue a un texto dado. Todo lo demás — responder preguntas, programar, traducir, razonar — emerge de repetir esa predicción una y otra vez.

La idea en una frase

Si le das "El cielo es de color", un LLM no "sabe" que el cielo es azul: calculó, a partir de patrones estadísticos de miles de millones de textos, que la palabra "azul" tiene la mayor probabilidad de continuar esa frase.

🔤El modelo no lee letras, lee tokens

¿Qué es un token?

Antes de procesar cualquier texto, el modelo lo parte en tokens: pedazos de palabra (a veces la palabra completa, a veces un fragmento) que se mapean a un número. "Tokenizar" es el primer paso de todo LLM, sea para leer tu prompt o para escribir su respuesta.

¿Por qué subpalabras y no palabras enteras?

Si tokenizara por palabra completa, necesitaría un "diccionario" gigante y no sabría qué hacer con palabras nuevas ("chatgepeteable"). Partiendo en subpalabras frecuentes, cualquier palabra —incluso inventada— se puede armar combinando piezas conocidas.

texto → tokens → números → el modelo trabaja con números "gato" podría ser 1 token · "extraterrestre" podría ser 3-4 tokens

📍Cada token es un punto en el espacio

¿Qué es un embedding?

Una vez tokenizado el texto, cada token se convierte en un vector: una lista de cientos o miles de números que representa su "significado" según cómo se usa en el lenguaje. Palabras con significados parecidos terminan con vectores parecidos — es decir, cerca en ese espacio.

¿De dónde salen esos números?

No los define nadie a mano: el modelo los aprende durante el entrenamiento, ajustándolos hasta que palabras que aparecen en contextos similares ("rey" y "reina", "gato" y "perro") queden ubicadas cerca entre sí.

similitud(A, B) = coseno del ángulo entre los vectores de A y B 1 = idénticos en significado · 0 = sin relación · -1 = opuestos

🔗Self-attention: el corazón del Transformer

El problema a resolver

Una misma palabra cambia de sentido según el contexto: en "el banco del río" y "el banco me cobró interés", "banco" significa cosas distintas. El modelo necesita que cada palabra "mire" a las demás palabras de la frase para entender su rol.

Cómo lo resuelve

El mecanismo de atención calcula, para cada palabra, un peso hacia todas las demás: cuánto debería "prestarle atención" a cada una para representarla mejor. Esto se hace en paralelo para toda la frase — por eso los Transformers reemplazaron a los modelos secuenciales (RNN) que leían palabra por palabra.

Attention(Q, K, V) = softmax( Q · Kᵀ / √d ) · V cada palabra genera una "consulta" (Q) y se compara contra las "claves" (K) de todas para ponderar sus "valores" (V)

📉Cómo se entrena un LLM

1. Pre-training

Se entrena con billones de palabras de internet, libros y código, con un único objetivo: predecir el siguiente token. Acá aprende gramática, hechos del mundo y razonamiento básico. Dura semanas y cuesta millones de dólares en cómputo.

2. Fine-tuning

Se lo re-entrena con ejemplos de instrucción-respuesta de alta calidad, curados por humanos, para que pase de "completar texto" a "seguir instrucciones y conversar" de forma útil.

3. RLHF

Reinforcement Learning from Human Feedback: humanos comparan pares de respuestas y el modelo se ajusta para preferir las que la gente prefiere — más útiles, honestas y seguras.

🎲De probabilidades a palabras: sampling

El modelo nunca "elige" con certeza

En cada paso, el modelo no devuelve una palabra: devuelve una distribución de probabilidad sobre todo su vocabulario. Un algoritmo de muestreo decide, a partir de esas probabilidades, qué token sale realmente.

Los tres diales que controlan la generación

  • Temperature: aplana o afila la distribución (más aleatorio vs. más determinista)
  • Top-k: solo considera las k opciones más probables
  • Top-p (nucleus): solo considera las opciones necesarias para acumular una probabilidad p

✍️Prompting avanzado

System prompt

Instrucciones "de fondo" que fijan el rol, tono y reglas del modelo antes de que empiece la conversación.

Few-shot

Mostrarle al modelo 1-2 ejemplos de pregunta-respuesta antes de tu pregunta real, para que copie el patrón y formato.

Chain-of-thought

Pedirle explícitamente que "piense paso a paso" mejora mucho la precisión en problemas que requieren razonamiento.

⚠️Lo que un LLM no hace bien

🌀 Alucinaciones

Como siempre predice "lo más probable", puede generar datos, citas o fuentes que suenan coherentes pero son inventados. No "sabe" que está mintiendo: no tiene forma interna de verificar hechos.

📏 Ventana de contexto

Solo "recuerda" una cantidad limitada de tokens (el prompt + la conversación). Lo que quedó afuera de esa ventana, literalmente no existe para el modelo en ese momento.

⚖️ Sesgos

Si el texto de entrenamiento contiene sesgos (de género, culturales, etc.), el modelo puede reproducirlos, porque aprendió patrones estadísticos del mundo real tal como es.

📋Cheat sheet: glosario de LLMs

10 términos clave

Token
Unidad mínima de texto que procesa el modelo: una palabra, parte de una palabra o un signo.
Embedding
Vector numérico que representa el significado de un token en un espacio de cientos de dimensiones.
Self-attention
Mecanismo que permite a cada token "mirar" a los demás para entender su contexto.
Transformer
Arquitectura de red neuronal basada en atención, base de casi todos los LLMs actuales.
Pre-training
Fase inicial de entrenamiento masivo prediciendo el siguiente token sobre texto general.
Fine-tuning
Re-entrenamiento sobre ejemplos curados para que el modelo siga instrucciones.
RLHF
Ajuste del modelo usando comparaciones de respuestas hechas por humanos.
Temperature
Parámetro que aplana (alta) o afila (baja) la distribución de probabilidad al generar.
Top-k / Top-p
Filtros que limitan cuántas opciones distintas puede elegir el modelo en cada paso.
Ventana de contexto
Cantidad máxima de tokens que el modelo puede "tener en cuenta" a la vez.

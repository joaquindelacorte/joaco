🧩 MÓDULO 1: Distribuciones Discretas (Binomial y Poisson)

💡 Conceptos Clave

  • Distribución Binomial: Aplica cuando hay un número fijo de ensayos independientes ($n$) con dos resultados posibles ("éxito" o "fracaso") y probabilidad constante ($p$).
    P(X = k) = (n! / (k!(n-k)!)) * p^k * (1-p)^(n-k)
  • Distribución de Poisson: Se usa para contar eventos en un intervalo continuo de tiempo o espacio, conociendo una tasa promedio ($\lambda$).
    P(X = k) = (e^(-λ) * λ^k) / k!

💻 Laboratorio de Simulación (Python)

Copia este script para comprobar las probabilidades exactas y acumuladas en tu entorno local:

import scipy.stats as stats

# === EJERCICIO 1.1: Piezas Defectuosas (n=25, p=0.04) ===
n, p = 25, 0.04
prob_exacta_2 = stats.binom.pmf(2, n, p)
prob_3_o_mas = 1 - stats.binom.cdf(2, n, p)

print(f"Binomial 1.1 - P(X=2): {prob_exacta_2:.4f}")
print(f"Binomial 1.1 - P(X>=3): {prob_3_o_mas:.4f}")

# === EJERCICIO 2.1: Sensor de fallas (Media = 2 por día) ===
lam = 2
prob_3_fallas = stats.poisson.pmf(3, lam)
print(f"Poisson 2.1 - P(X=3 en 1 día): {prob_3_fallas:.4f}")

Pregunta: Si un centro recibe en promedio 5 llamadas por hora, ¿cuál es el nuevo λ para 30 minutos?

Respuesta: El parámetro λ se ajusta proporcionalmente al intervalo. Si en 60 minutos se reciben 5 llamadas, en 30 minutos se espera recibir la mitad:

λ_nuevo = 5 * (30 / 60) = 2.5 llamadas

Para calcular la probabilidad de 0 llamadas (k=0):

P(X = 0) = (e^(-2.5) * 2.5^0) / 0! = e^(-2.5) ≈ 0.0821 (8.21%)

📈 MÓDULO 2: Distribución Normal e Intervalos de Confianza

💡 Conceptos Clave

  • Estandarización: Convierte cualquier variable normal X ~ N(μ, σ) a la distribución estándar Z ~ N(0, 1) mediante:
    Z = (X - μ) / σ
  • ¿Z o t de Student?: Usamos Z si la desviación estándar poblacional (σ) es conocida. Usamos t de Student si es desconocida y la estimamos mediante la desviación muestral (s).

📝 Guía de Resolución Paso a Paso

Resolución del Ejercicio 4.2 (Muestra de piezas):

Datos: n = 16, x̄ = 50.2 mm, s = 1.2 mm, Confianza = 95%.

  1. Grados de libertad (gl): gl = n - 1 = 16 - 1 = 15.
  2. Valor crítico (t): Para un nivel de confianza del 95% (α = 0.05) con 15 gl en dos colas, el valor de tabla es t(0.025, 15) = 2.131.
  3. Margen de error (E):
    E = t * (s / √n) = 2.131 * (1.2 / √16) = 2.131 * 0.3 = 0.6393 mm
  4. Intervalo de Confianza:
    IC = [50.2 - 0.6393; 50.2 + 0.6393] = [49.56 mm; 50.84 mm]

🧠 Desafío Interactivo: Análisis Conceptual

Pregunta: ¿Qué sucede con el intervalo de confianza si el nivel de confianza aumenta al 99%? ¿Por qué?

Respuesta: El intervalo se vuelve más ancho. Al exigir una mayor certeza (99% en lugar de 95%), el valor crítico de la distribución (Z o t) aumenta. Esto incrementa el margen de error y amplía la longitud del intervalo para asegurar que contenga el verdadero parámetro.

📐 MÓDULO 3: Tamaño de Muestra y Regresión Lineal

💡 Conceptos Clave

  • Tamaño de Muestra: Determina cuántas observaciones mínimas necesitas para no superar un error máximo (E) dado.
    n = ((Z_(α/2) * σ) / E)^2
  • Regresión Lineal Simple (ŷ = a + bx): Modela la tendencia entre una variable predictora (X) y una de respuesta (Y). La pendiente (b) indica cuánto cambia Y por cada unidad de incremento en X.

Predecir: ¿Qué nota se estima para un alumno que estudia 5 horas?

Sustituimos x = 5 directamente en la ecuación de nuestra recta estimada:

ŷ = 2.7 + 0.65 * (5) = 2.7 + 3.25 = 5.95

Resultado: Se predice una nota de 5.95.

🛠️ Recordatorio para el Examen

  • ¡Redondeo en Tamaño de Muestra! El valor de n siempre se redondea hacia el entero superior inmediatamente (ej: si da 61.2, se usa 62), asegurando así cumplir con el margen de error máximo requerido.
  • Poisson: Ajusta siempre la tasa λ si cambia la unidad de tiempo o espacio en la pregunta.

📐 Sección A — Conceptos Básicos (20 pts)
A1

Control de temperatura con termostato

Un termostato enciende la calefacción cuando la temperatura baja de 18 °C y la apaga cuando supera 22 °C.

a) ¿Lazo abierto o cerrado?

✅ Lazo cerrado

El termostato mide continuamente la temperatura (retroalimentación) y decide si actuar. La salida (temperatura) influye sobre la decisión de encender/apagar → existe un lazo de realimentación.

b) Identificación de elementos

🌡️ Sensor

Termistor o sensor de temperatura del termostato — mide la variable controlada (temperatura ambiente).

🧠 Controlador

Lógica del termostato — compara con el rango (18–22 °C) y decide encender o apagar.

⚡ Actuador

Resistencia calefactora / unidad de calefacción — modifica la temperatura del ambiente.

c) Sin histéresis (conmuta exactamente en 20 °C)

⚠️ Chattering (ciclo límite)

El sistema entraría en chattering: cualquier mínima variación alrededor de 20 °C dispara la acción de encendido/apagado en ciclos muy cortos. Esto:

  • Degrada el actuador mecánicamente (desgaste de contactos)
  • Genera oscilaciones permanentes sin estabilización real
  • Consume energía innecesariamente

La histéresis (banda 18–22 °C) existe exactamente para evitar este problema.

A2

Sistema de primer orden G(s) = 3 / (2s + 1)

a) Estado estacionario con escalón de amplitud 2
y_ss = lim[s→0] s · G(s) · (2/s) = G(0) · 2 = (3/1) · 2 = 6 Teorema del valor final: lim[t→∞] y(t) = lim[s→0] s·Y(s)

✅ y_ss = 6

b) Tiempo para alcanzar el 63 % del valor final

τ = 2 segundos

La constante de tiempo es el coeficiente de s en el denominador: τ = 2 s. Por definición, el 63,2 % del valor final se alcanza exactamente en t = τ = 2 s.

c) Si se duplica el coeficiente de s → G(s) = 3/(4s+1)

⏳ Sistema más lento (τ pasa de 2 a 4 s)

Mayor τ → la exponencial decae más despacio → el sistema tarda más en alcanzar el estado estacionario. El valor final no cambia (y_ss sigue siendo 6), solo cambia la velocidad de respuesta.

🔋 Sección B — Sistemas de 1er Orden (25 pts)
B1

Circuitos RC — constante de tiempo

a) Constante de tiempo τ = R·C

Circuito 1: τ₁ = 1 s

R₁ = 1 kΩ, C = 1000 µF

τ₁ = 1000 Ω × 0,001 F = 1 s

Circuito 2: τ₂ = 10 s

R₂ = 10 kΩ, C = 1000 µF

τ₂ = 10 000 Ω × 0,001 F = 10 s
b) ¿Cuál se carga más rápido?

✅ Circuito 1 (τ₁ = 1 s)

Con menor resistencia, el capacitor puede recibir más corriente en el mismo tiempo → se carga más rápido. La resistencia limita la velocidad de carga: i(t) = V/R · e^(-t/τ).

c) Gráficos de carga — Circuito RC interactivo
Escalón de entrada: 5 V
Circuito 1 (τ=1 s) Circuito 2 (τ=10 s) Setpoint 5 V
Lectura clave: A t = 1τ el C1 ya llegó al 63 % (3,15 V), mientras que C2 apenas alcanzó el 10 % (0,48 V). A t = 5τ = 5 s, C1 está al 99 %; C2 recién está en el 39 %.
B2

Termómetro digital — sistema de primer orden térmico

Datos: sube de 20 °C a 80 °C (ΔT_total = 60 °C). A t = 5 s, lectura = 58 °C → subió 38 °C.

a) Constante de tiempo τ
y(t) = ΔT_total · (1 - e^(-t/τ)) 38 = 60 · (1 - e^(-5/τ)) e^(-5/τ) = 1 - 38/60 = 0,3667 -5/τ = ln(0,3667) = -1,003 τ ≈ 5 / 1,003 ≈ 5 s

✅ τ ≈ 5 segundos

b) Tiempo para llegar a 79 °C (↑ 59 °C)
59 = 60 · (1 - e^(-t/5)) e^(-t/5) = 1/60 t = 5 · ln(60) ≈ 5 × 4,094 ≈ 20,5 s

✅ t ≈ 20,5 s

Equivale a ~4τ (98,2 % del valor final). Regla práctica: a 4τ el sistema está al 98 %.

c) Punta más gruesa (mayor capacidad térmica)

⏳ τ aumenta → respuesta más lenta

τ_térmico = R_térmica × C_térmica. Al aumentar la masa/capacidad térmica de la punta (C), τ aumenta → el termómetro tardará más en reflejar cambios de temperatura. La lectura tendrá mayor retardo.

📍 Sección C — Polos y Estabilidad (20 pts)
C1

Tres funciones de transferencia

G₁(s) = 1/(s+2) → polo: s = -2 (Re < 0) → ESTABLE G₂(s) = 1/(s-2) → polo: s = +2 (Re > 0) → INESTABLE ⚠️ G₃(s) = 1/(s²+2s+5) → polos: s = (-2 ± √(4-20))/2 = -1 ± 2j (Re < 0) → ESTABLE

G₁ — Estable

Polo en s = −2. Parte real negativa → respuesta exponencial decreciente → converge.

G₂ — Inestable ⚠️

Polo en s = +2. Parte real positiva → la respuesta crece exponencialmente sin límite.

G₃ — Estable, oscilatorio

Polos complejos −1 ± 2j. Parte real negativa → oscilación amortiguada → converge.

b) ¿G₃ oscila?

Sí, oscila con amortiguamiento. La parte imaginaria (±2j) genera oscilación; la parte real negativa (−1) provoca que esa oscilación decaiga → sistema subamortiguado estable.

c) G₁ con Kp = 10 en lazo cerrado
T(s) = (Kp · G₁) / (1 + Kp · G₁) = (10/(s+2)) / (1 + 10/(s+2)) = 10 / (s + 2 + 10) = 10 / (s + 12)

✅ Polo LC en s = −12 — más rápido y sigue estable

La realimentación corrió el polo de −2 a −12: más negativo → exponencial que decae 6× más rápido. La estabilidad se mantiene.

C2

Sistema con polos en s = −1 ± 2j

a) Estabilidad

✅ Estable

Parte real = −1 < 0 → ambos polos en el semiplano izquierdo.

b) ¿Habrá sobrepaso?

Sí — sistema subamortiguado

Polos complejos con parte imaginaria ≠ 0 → respuesta subamortiguada → la salida supera el setpoint antes de estabilizarse.

ζ = Re/|polo| = 1/√(1²+2²) = 1/√5 ≈ 0,45

c) Polos en −3 ± 2j

Más rápida y menos sobrepaso

  • Re más negativa → decaimiento más veloz → respuesta más rápida
  • ζ_nuevo = 3/√13 ≈ 0,83 (vs 0,45) → mayor amortiguamiento → menos sobrepaso
d) Mapa de polos en el plano complejo
Plano complejo s = σ + jω · Eje horizontal: σ (Re), eje vertical: jω (Im)
Polos −1 ± 2j Zona inestable (Re > 0) Zona estable (Re < 0)
🎛️ Sección D — Control On-Off y Proporcional (20 pts)
D1

Control de nivel — G(s) = 1/(s+1)

a) Control On-Off con histéresis — ¿se estabiliza en el setpoint?

⚡ No se estabiliza — ciclo límite

El nivel oscila dentro de la banda de histéresis. La bomba enciende cuando el nivel baja del umbral inferior y apaga cuando supera el superior → genera una oscilación sostenida pero acotada (ciclo límite).

Es aceptable operativamente pero no es un punto de equilibrio exacto. El error nunca es cero.

b) Control Proporcional Kp = 3 — ¿llega al setpoint?
T(s) = Kp·G(s) / (1 + Kp·G(s)) = (3/(s+1)) / (1 + 3/(s+1)) = 3 / (s + 1 + 3) = 3 / (s + 4) y_ss = T(0) · 1 = 3/4 = 0,75 Offset = 1 - 0,75 = 0,25 → 25%

⚠️ Error en estado estacionario = 25 %

El control proporcional puro siempre deja offset: necesita error para generar señal de control. A mayor Kp, menor offset — pero nunca cero.

c) ¿Qué agregar para eliminar el offset?

✅ Acción Integral → Controlador PI o PID

La integral acumula el error en el tiempo y genera señal de control incluso cuando el error instantáneo es pequeño → elimina el offset en régimen permanente.

C_PI(s) = Kp · (1 + 1/(Ti·s)) — el polo en s=0 garantiza error cero ante escalón.

D2

Respuesta con sobrepaso — G(s) = 1/(s+1)

La gráfica muestra una respuesta que supera el setpoint y luego se estabiliza en 1 (sin offset).

a) Tipo de controlador

Sin offset → hay acción integral. Con sobrepaso → ganancia proporcional alta.
Controlador PI o PID.

b) ¿Por qué hay sobrepaso?

La ganancia proporcional alta hace que el sistema reaccione con inercia: cuando la salida se acerca al setpoint, la señal acumulada aún lleva al sistema más allá del objetivo.

c) Si se reduce Kp

  • Sobrepaso disminuye (más amortiguada)
  • Tiempo de establecimiento aumenta (más lenta)
  • Trade-off: menos sobrepaso ↔ más tiempo

'DisplayName', sprintf('Kp=%d (offset=%.3f)', Kp, 1-dcgain(T))); printf('Kp=%d: y_final=%.4f, offset=%.4f\n', Kp, dcgain(T), 1-dcgain(T)); end plot(t, ones(size(t)), 'k--', 'LineWidth', 1.5, 'DisplayName', 'Setpoint'); legend('Location', 'southeast'); xlabel('Tiempo (s)'); ylabel('Salida y(t)'); title('Respuesta LC — G(s)=1/(s+1), distintos Kp'); grid on;
Conclusión

Offset = 1 / (1 + Kp)

A mayor Kp → menor offset, pero el offset nunca es cero con control proporcional puro. Para eliminarlo completamente se necesita acción integral (PI o PID). A Kp → ∞ el offset → 0 pero el sistema se vuelve menos robusto.

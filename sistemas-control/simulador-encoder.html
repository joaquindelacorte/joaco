📚 Fundamentos teóricos

🔵 Geometría del Disco

El disco codificador tiene N ranuras distribuidas uniformemente sobre la pista de lectura de radio r.

d = (2π · r) / N Paso entre centros de ranura · Δθ = 360° / N d [mm] · w = d/2 (ancho ventana, DC=50%)

A mayor PPR y menor radio, las ranuras son más estrechas y las exigencias mecánicas más altas.

🟢 Señal en Cuadratura A / B

Dos fotosensores desfasados 90° generan señales que permiten detectar posición y sentido de giro:

f_pulso = (N · n) / 60 [Hz] T_pulso = 1 / f_pulso · T_alto = T_pulso / 2
  • CW: A adelanta a B en T/4 (90°)
  • CCW: B adelanta a A en T/4 (90°)

🟠 Modelo RC — Transformada de Laplace

La resistencia de pull-up y la capacitancia parásita del cable forman un filtro paso-bajo de primer orden:

H(s) = V_out(s) / V_in(s) = 1 / (τs + 1) τ = R · C [s] · · · f_c = 1 / (2πτ) [Hz] Respuesta: v_out(t) = V_max · (1 − e^(−t/τ)) en carga

🔴 Criterio de Fallo a Alta Velocidad

El controlador QEI solo detecta un pulso si la señal cruza los umbrales durante el tiempo disponible:

V_peak = V_max / (1 + e^(−T_alto/τ)) Si T_alto < 3τ → atenuación severa Si V_peak < V_IH → PÉRDIDA DE CONTEO

A mayor velocidad o mayor τ (R·C), el riesgo de pérdida aumenta. El osciloscopio muestra la degradación en tiempo real.

📝 Ejercicios resueltos — Parcial tipo

Ejercicios del parcial tipo (Ing. Tirabasso). Cada problema incluye la resolución analítica y el vínculo con lo que podés ver en el simulador de arriba.

📌 Problema B.1 — Dos circuitos RC (12 pts)

Se tienen dos circuitos RC excitados con un escalón de 5 V:

  • Circuito 1: R = 1 kΩ, C = 1000 µF → τ₁ = ?
  • Circuito 2: R = 10 kΩ, C = 1000 µF → τ₂ = ?

a) Constante de tiempo τ = R · C

τ = R · C τ₁ = 1×10³ Ω · 1×10⁻³ F = 1 s τ₂ = 10×10³ Ω · 1×10⁻³ F = 10 s

→ Cómo verlo en el simulador: ponele R = 1000 Ω y C = 1000000 nF. El osciloscopio muestra la curva de carga exponencial. Después aumentá R a 10000 Ω — la curva se "aplana" (tarda más en subir).

b) ¿Cuál se carga más rápido?

El Circuito 1 (τ₁ = 1 s < τ₂ = 10 s). Justificación física: con la misma carga (C), una resistencia más pequeña deja pasar más corriente → el capacitor se carga más rápido. La resistencia "frena" la corriente de carga.

Regla: el capacitor llega al 63% de la tensión final en exactamente 1τ, y al 95% en 3τ.

c) Tensión del capacitor en función del tiempo

v_C(t) = V_max · (1 − e^(−t/τ)) Circuito 1: v_C(t) = 5 · (1 − e^(−t/1)) [V] Circuito 2: v_C(t) = 5 · (1 − e^(−t/10)) [V]

En el gráfico: la curva del Circuito 1 sube más empinada y llega a 5 V antes. La del Circuito 2 es más "perezosa". Ambas convergen a 5 V en estado estacionario.

📌 Problema B.2 — Termómetro digital de primer orden (13 pts)

Al sumergir el termómetro: T₀ = 20 °C → T∞ = 80 °C. A los 5 s la lectura es 58 °C.

a) Calcular τ (constante de tiempo)

T(t) = T∞ + (T₀ − T∞) · e^(−t/τ) 58 = 80 + (20 − 80) · e^(−5/τ) 58 − 80 = −60 · e^(−5/τ) → −22 = −60 · e^(−5/τ) e^(−5/τ) = 22/60 = 0.3667 −5/τ = ln(0.3667) = −1.003 → τ ≈ 5 s (Coincide con la definición: al tiempo τ el sistema alcanzó el 63.2% del cambio total)

Verificación: 20 + (80−20)·(1−e^(−5/5)) = 20 + 60·0.632 = 57.9 °C ≈ 58 °C ✓

b) ¿Cuánto tarda en llegar a 79 °C?

79 = 80 − 60 · e^(−t/5) e^(−t/5) = 1/60 = 0.01667 −t/5 = ln(0.01667) = −4.094 t ≈ 20.5 s (≈ 4τ) Regla práctica: 4τ ≈ 98% del valor final

c) ¿Qué pasa con τ si la punta es más gruesa?

τ aumenta. La analogía térmica-eléctrica es: masa térmica ↔ capacitor (C), resistencia térmica ↔ resistor (R). Mayor masa = más "capacitor" = más τ = respuesta más lenta. El termómetro tarda más en registrar el cambio real de temperatura.

→ Conexión con el encoder: en el simulador, el capacitor parásito C cumple el mismo rol — a mayor C, mayor τ, y la señal tarda más en cargarse a V_max.

📌 Problema A.2 — Función de transferencia G(s) = 3/(2s+1) (10 pts)

a) Salida en estado estacionario — escalón de amplitud 2

y_ss = K · A = (ganancia DC) · (amplitud escalón) Ganancia DC = G(0) = 3/(2·0+1) = 3 y_ss = 3 · 2 = 6 Regla: en estado estacionario s→0, así que G(s)|_{s=0} es la ganancia DC

b) Tiempo para alcanzar el 63% del valor final

τ = 2 s G(s) = 3/(2s+1) → forma estándar K/(τs+1) con τ = 2 s Al tiempo t = τ = 2 s, la salida vale ≈ 63% de 6 = 3.78

→ Esto es exactamente el τ del encoder: en el simulador, τ = R·C. Si τ = 2 s, configurá R = 2 MΩ, C = 1 µF para ver la misma curva.

c) Si se duplica el coeficiente de s → ¿más rápido o más lento?

Si G(s) = 3/(4s+1), ahora τ = 4 s (antes era 2 s). El sistema se vuelve más lento — tarda más en llegar al 63% de la salida final. El coeficiente de s en el denominador es directamente la constante de tiempo τ.

📌 Problema C.1 — Polos y estabilidad (10 pts)

G1 = 1/(s+2) · G2 = 1/(s−2) · G3 = 1/(s²+2s+5) Regla: sistema estable ↔ todos los polos con parte real < 0 (plano izquierdo)

✅ G1 — Estable

Polo en s = −2 (parte real negativa). La respuesta decae exponencialmente.

❌ G2 — INESTABLE

Polo en s = +2 (parte real positiva → plano derecho). La respuesta crece exponencialmente sin límite.

G3 — ¿Oscila? Polo complejo conjugado

s² + 2s + 5 = 0 s = (−2 ± √(4−20)) / 2 = −1 ± 2j Parte real = −1 < 0: ESTABLE. Parte imaginaria ≠ 0: OSCILA amortiguado

La respuesta es una senoide amortiguada — oscila pero con amplitud decreciente hasta estabilizarse. Conexión con el encoder: el semáforo del simulador detecta cuándo la señal no alcanza los umbrales; si el sistema tuviera polos complejos como G3, la señal oscilaría antes de estabilizarse.

c) G1 con Kp = 10 en lazo cerrado — ¿sigue estable?

G_LC(s) = Kp·G1 / (1 + Kp·G1) = 10/(s+2) / (1 + 10/(s+2)) = 10 / (s+2+10) = 10/(s+12) Polo en s = −12 → parte real negativa → ESTABLE ✓

La ganancia proporcional solo desplaza el polo más a la izquierda — hace el sistema más rápido, no inestable. τ_LC = 1/12 s (antes era 1/2 s).

📌 Problema D.1 — Control On-Off y Proporcional (10 pts)

Planta: G(s) = 1/(s+1). Bomba: encendida u = 2 L/s, apagada u = 0.

a) Control On-Off con histéresis — ¿el nivel se estabiliza?

No se estabiliza exactamente — oscila dentro de la banda de histéresis. Cuando el nivel baja del límite inferior, la bomba enciende; cuando sube al límite superior, apaga. El nivel "rebota" permanentemente entre esos dos valores. Ventaja: simple. Desventaja: nunca llega al setpoint exacto.

b) Control Proporcional Kp = 3 — ¿llega al setpoint?

G_LC = Kp·G / (1 + Kp·G) = 3/(s+1) / (1 + 3/(s+1)) = 3 / (s+1+3) = 3/(s+4) Valor final (escalón unitario): G_LC(0) = 3/4 = 0.75 ≠ 1 Offset = 1 − 0.75 = 0.25 (25% de error permanente)

El control P no elimina el offset. El error permanente es e_ss = 1/(1+Kp) = 1/(1+3) = 0.25.

c) ¿Qué agregar para eliminar el offset?

Una acción Integral (I). El controlador PI acumula el error en el tiempo y lo corrige hasta que el error sea cero. La acción I elimina el error en estado estacionario para referencias de tipo escalón.

  • Solo P: rápido, pero con offset
  • PI: sin offset, algo más lento
  • PID: sin offset, con derivativa para mejorar la respuesta transitoria

📌 Problema E.1 — Simulación en Octave (15 pts)

Planta: G(s) = 1/(s+1), controlador Kp, escalón unitario. Objetivo: ver el efecto del Kp sobre el offset.

Solución analítica del offset en función de Kp

y_ss = Kp / (1 + Kp) Kp = 2 → y_ss = 2/3 ≈ 0.667 → offset = 0.333 Kp = 5 → y_ss = 5/6 ≈ 0.833 → offset = 0.167 Kp = 10 → y_ss = 10/11 ≈ 0.909 → offset = 0.091 Conclusión: a mayor Kp, menor offset (pero nunca = 0 con solo control P)

Código Octave

G = tf([1],[1 1]); % Planta G(s) = 1/(s+1) t = 0:0.01:10; % Vector tiempo 10 seg figure; hold on; Kps = [2, 5, 10]; colors = {'b','r','g'}; for i = 1:length(Kps) Kp = Kps(i); C = tf([Kp],[1]); % Controlador P LC = feedback(C*G, 1); % Lazo cerrado [y,t] = step(LC, t); plot(t, y, colors{i}, 'LineWidth', 1.5); end plot(t, ones(size(t)), 'k--'); % Setpoint legend('Kp=2','Kp=5','Kp=10','Setpoint'); xlabel('Tiempo [s]'); ylabel('Salida y(t)'); title('Respuesta al escalon - Control Proporcional');

Las tres curvas convergen a su respectivo y_ss. Ninguna llega a 1.0 exactamente — eso es el offset del control proporcional.

d) Conclusión: relación Kp ↔ offset

A mayor Kp, menor offset — pero el offset nunca desaparece con control P puro. La fórmula e_ss = 1/(1+Kp) muestra que necesitaríamos Kp → ∞ para anularlo, lo que haría el sistema inestable o con oscilaciones.

La solución real es agregar acción integral (PI o PID), que integra el error y lo corrige hasta hacerlo exactamente cero.
